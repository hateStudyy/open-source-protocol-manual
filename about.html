关于本站

网站用途

本站为自用学习站点，主要用于记录和对照阅读常见开源许可证与计算机核心协议的中英文内容，便于理解条款含义、规范表述与适用场景。

收录范围

  • 开源许可证：MIT、Apache-2.0、BSD-2-Clause、BSD-3-Clause、GPL v2、GPL v3、LGPL v3、MPL 2.0
  • 计算机核心协议：HTTP / HTTPS、TCP / UDP、DNS、WebSocket、RESTful 规范

内容说明

  • 英文原文保持原版格式，来源于各协议官方发布文本；中文翻译力求准确、流畅，仅用于学习对照。
  • 正式商业或法律用途，请以各协议官方原版英文文本为准。
  • 关键条款（商用限制、署名要求、免责、衍生作品约束等）以浅蓝色背景高亮。

技术实现

纯静态站点，仅使用 HTML / CSS / 原生 JavaScript，无后端、无第三方依赖、无广告、无统计。支持深浅色模式切换、侧边栏折叠、刷新后保留状态。
